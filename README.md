# Advertisting

Advertisting is a bright little home for a Discord bot that handles music, moderation, and the repetitive server chores nobody wants to babysit. The site runs on Next.js, TypeScript, and plain CSS, with no UI framework sitting between the design and the browser.

I first made this site in 2021 and accidentally started a tradition: every few years I come back, question my old CSS choices, and rebuild the whole thing. The bot has survived every redesign. My taste has survived most of them. Thanks for sticking around and keeping the tradition alive with me.

Run `npm install` and `npm run dev`, then open `http://localhost:3000`. If you have a Discord invite URL, copy `.env.example` to `.env.local` and add it there. Before shipping, `npm run lint`, `npm run typecheck`, and `npm run build` cover the important checks.

The project is MIT licensed. Please do not use it for evil. That part is also becoming a tradition.
